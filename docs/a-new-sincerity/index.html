04the feedback loop

the creation changed its creator.

Making these records did more than represent an alternate version of me. Each interpretation became a song I could replay and argue with. Eventually, the songs entered my memories. The map modifies the territory.

Knowing that a voice, a band, or a memory was constructed did not make the attachment disappear. It became one more fact inside the attachment.
